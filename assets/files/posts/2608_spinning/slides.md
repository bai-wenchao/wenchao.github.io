# 这是什么？

- 命令行工具"干活"时显示的加载动画：一个旋转的盲文点阵 `⠋ ⠙ ⠹ ⠸ ⠼ ⠴ ⠦ ⠧ ⠇ ⠏`
- Claude Code 在点阵旁轮换显示一个动词，约每 **1.4 秒**换一个，让等待不那么无聊
- 这套传统可追溯到《模拟城市》的加载文案 `Reticulating splines` —— 用一本正经的技术词，掩饰"其实只是在加载"
- 词表混合了正经（`Thinking`）、做菜（`Simmering`）、理科（`Photosynthesizing`）和纯胡闹（`Flibbertigibbeting`）

> 快捷键：`n` / `→` 下一页　`p` / `←` 上一页　`?` 帮助　`Esc` 总览　`f` 全屏　`s` 演讲者备注

# 彩蛋与词源

这一类词不在描述"正在做什么"，而是在跟懂的人眨眼——它们是整个词表里最值得收藏的。

## [Clauding]{.verb} —— 自指梗

Claude 把自己的名字当动词用——"作为 Claude 在干活"。整个词表里唯一的品牌自创词，带着一点腼腆的自嘲。

## [Reticulating]{.verb} —— 游戏圈第一名梗

来自《模拟城市》的加载文案 `Reticulating splines`（"把样条结成网状"）。听起来极专业，实际什么都没干——从此成为"假装在加载"的文化符号，被无数游戏致敬。

## [Gitifying]{.verb} —— 开发者彩蛋

把东西变成 git 仓库。只有程序员会会心一笑的内部梗。

## [Quantumizing]{.verb} —— 流行词嘲讽

嘲讽那些给一切套上"量子"前缀的伪科技话术——量子水、量子袜、量子化你的 spinner。
